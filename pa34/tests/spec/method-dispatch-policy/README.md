# Source method-dispatch policy

This draft owns the LIB-112 source declaration and its required cross-edition
consumers. PA31 supplies original trait/attribute authority; PA19 supplies method
selection; PA34 supplies the editions required by the real library graph; PA33
supplies genuine Box identity/storage. Broader attribute and edition closure
remains in PA40, and metadata transport belongs to PA29. This packet does not
activate an assignment or declare the whole policy implemented.

The pinned parser accepts a single nonempty parenthesized list of `array` and
`boxed_slice` words on an actual trait, with rustc_attrs or an authentic macro
allowance. Duplicated keys/attributes, extra arguments, other targets and an
unsafe wrapper fail. The source producer retains both bits with the actual
configured owner, original image, complete trait item and bound definition.
An absent source policy still requires an actual trait. Unknown imported
authority is distinct from checked absence. Older export profiles must reject
unencoded intent.

The pinned method probe checks the actual adjusted receiver, before transforming
the method's Self parameter. It skips an array receiver before Rust 2021 and an
actual Box<[T]> receiver before Rust 2024. It reads the method-name token's
edition. A borrowed receiver is not the corresponding owned receiver: the
original `&self` boxed fixture produces 7 in every edition, while the by-value
fixture produces 9/9/7 in 2018/2021/2024. Qualified trait calls are unaffected;
a plain struct named Box acquires no standard-library identity.

`contract.json` freezes 43 inputs and seven native predictions. All 258 pinned
Rust metadata/object outcomes and 21 native executions match. The first
prediction incorrectly treated `&Box` as Box; its failed receipt and exact
predecessor contract are retained. The unchanged original source now has the
correct expectation, and a separate by-value input preserves the intended
opposing result. No Rust-positive language outcome was inverted.

Generated objects and executables are pruned; raw diagnostics, source hashes,
predictions and receipts are retained under obj/parallel/method-dispatch-policy-v1.

Candidate declaration qualification and the original-core observation are tracked
in the library blocker journal. Receiver filtering, mixed-origin method tokens,
genuine Box and older-edition native consumers and authenticated policy transport
remain requirements. The existing custom-auto-trait admission boundary also
rejects the unchanged Rust-positive `auto-trait.rs` before attribute processing;
it remains an explicit language prerequisite. The separate source-auto fixture
uses the actual authenticated Send role to validate an auto trait target without
substituting a nominal lookalike or claiming general custom-auto support.
