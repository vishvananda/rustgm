# Crate-owned source preludes

Twenty frozen source outcomes distinguish the host and each guest's actual
prelude from ordinary lexical globs. Each crate can select a real public module;
a later selector in the same source crate replaces the previous selection,
including its otherwise absent names. It does not merge those modules. Each
root owns its `prelude_import` request. The selected use owner, source image,
attribute/effect, tree, module and target remain authenticated under the existing
source payer. Staged replacement keeps the old selection until lookup commits.

The inputs cover actual type identity and trait-method lookup, host/sibling
isolation, source editions, automatic fallback, lexical shadowing and
`no_implicit_prelude`. Imported opaque, captured and mixed-site macros distinguish
lexical definition privacy from invoking-crate prelude fallback for type names,
unit constructors and actual method calls. The original opaque fixture expecting
the host's type is an E0308 identity opponent; its independently accepted successor
expects the guest's type. No source bytes or required accepted operation were
silently weakened after the first prediction was refuted.

`outcomes.json` lists/hashes every input and preserves the original declaration
and failure provenance. All20 independent statuses and required diagnostics match,
combining18 unchanged observations with two amended cases. The immutable913
baseline accepts the automatic-only guest and rejects every authored guest
selector at its session-global singleton fence; those early rejections do not
qualify the intended negative semantics. The candidate now matches all20 declared
source outcomes, with five exact guest/prelude/edition controls, strict selected
Clippy, formatting, architecture, harness and upstream checks passing. The linked
private harness reached its compile deadline before execution; its16 prelude
controls remain pending CI. Actual std graph replay is pending a new immutable
compiler from the clean checkpoint.
The adopted PA24 ordinary/bootstrap behavior, source metadata publication, native
