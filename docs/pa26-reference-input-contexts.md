# Reference input contexts prerequisite

This prerequisite lets an ordinary method argument use the current call's already selected reference input before its operand is checked. It also corrects the earlier borrow-value contextual expectation bug exposed by that inference. It adds no trait-specific coercion or factory permission.

`PrepareCallArgument` replaces `Enter` only for fixed-prefix call arguments when retained call obligations exist. The bounded reference-prefix query asks the existing per-call Inputs inventory to refine an unresolved referent. It uses the complete application identity, append cursor, once-only seed, existing selection continuation and retained evidence; final `CoerceCallArgument` still performs the conversion. Known inputs do not run another selection. Rigid generic inputs and nonselecting/declaration queries are unchanged. Primitive comparison candidates may infer an unconstrained RHS from a known supported primitive Self only during selecting queries; ordinary source candidates continue to compete, including local nominal RHS implementations in either source order.

A borrowed block/if/match/loop value receives an ordinary pointee coercion after its Enter subtree and before forming the outer borrow. Its context is installed before evaluating mutable-reference tails. Transparent wrappers are inspected to distinguish an actual place from a value expression; grouped places retain their old path. An unresolved inference head supplies no extra operand coercion. Concrete slice/str/object metadata is a weak construction hint, whereas rigid generic or unknown physical metadata remains a strong expectation. Final reference/unsizing and ordinary lifetime, move and loan proofs remain mandatory.
