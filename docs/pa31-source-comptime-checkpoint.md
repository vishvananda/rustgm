# Compile-time-only source functions

The qualified local implementation of rustc_comptime belongs to PA31 source
declarations, PA25 defining/call contexts and PA29 transport boundaries. It does
not complete those assignments or implement the original reflection intrinsic.
The owning inputs and independent predictions are retained in
[source-comptime](../pa31/tests/spec/source-comptime/contract.json).

Authenticate the internal feature, actual attribute form, unique active source
owner and supported free/inherent function declaration. Effective eligibility
is separate from written const syntax. A genuine constant initializer or inline
constant calls the marked function under Const; its own body is also checked
under Const even if unused. Ordinary const-function bodies retain conditional
effects, and ordinary runtime/closure bodies do not gain an implicit constant
root. Explicit const syntax on the marked declaration remains rejected.

Actual item aliases retain the target contract. Unsafe calls and regular/const
API availability keep their own checks. Function-pointer erasure and genuine
runtime calls through pointers or the supported callable machinery remain
accepted where pinned Rust accepts them. The marker grants no runtime intrinsic
implementation, promotion, native privilege or fabricated evaluation body.

An unused defining body is prepared through the existing typed defining-body
callback. A ComptimeDefinition request lends the single original CFG from the
existing execution owner and returns it after normal eligibility checking.
Generic/opaque templates retain their existing path; concrete originals move to
the normal prepared inventory. No duplicate original map, fake constant call,
common Header/Body/Node field or new whole-program sweep is introduced. Failed
and resumed work remains paid, and missing or changed owner/image evidence is a
hard failure.

The existing cold header promises share the prior header slot: SourceHeader is
80 bytes, Body 456 and Node 36. Widths8/32/128 use work 837/2853/10917 and retained
bytes 23632/53584/173392. These are bounded-work observations, not calibrated
wall-time speedup claims.
