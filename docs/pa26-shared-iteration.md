# Shared slice and array iteration checkpoint

This implements safe shared iteration for `&[T]`, `&[T; N]`, and canonical
`core::slice::Iter<'a, T>`, including `[T]::iter`, qualified slice calls and
specialized function-pointer reification. `T` need not be Copy or Clone. This is
an implementation checkpoint; PA26 remains planned and no text references are
generated by this change.

The draft `pa26/tests/shared-iteration-outcomes.json` retains 26 independently
declared Rust 1.98/2024 outcomes (18 accepted executable programs and eight
rejections), with unchanged source digests and explicit LowIR inspection modes.
`language_operators::shared_iterators` owns source/native comparison. Its native
test is explicitly ignored on installations without the external backend.
The `iter-clone-no-element-clone` program checks the **Clone bound**, not an
invocation of `Iter::clone`; executable clone materialization remains required.

## Identity, proof and execution

The resolver reserves canonical collection identities after source definitions.
The new constructorless Iter is a real private-field library nominal with one
lifetime and one sized type parameter. Existing canonical identities keep their
order. Optional constructor metadata cannot turn Iter into source-constructible
syntax; existing nominal/Option/Result constructors retain their real DefIds.

A lazy collection catalog records four exact contracts: shared slice
IntoIterator, shared array IntoIterator, Iter Iterator, and the inherent slice
`iter` method. Each selected method retains its complete Instance, real
associated Item/IntoIter obligations and ordinary checked generic original.
Both incremental and batch collectors prove those originals before specialized
publication. Prepared registry state cannot authorize a factory; conformance and
complete publication are required. Diagnostic origins supply no AST ownership or
proof assumptions.

The checked `next` body keeps the source lifetime separate from its mutable
receiver lifetime. It tests the selected slice length, returns None when empty,
otherwise borrows the first element and rest, stores the rest through the
receiver and returns Some(first). It neither reads nor moves an element value.
Array formation uses the existing checked array-to-slice adjustment and its
extent evidence. Rest views retain their selected metadata rather than the
backing array extent. ForPlan prepares the exact selected iterator and Option
storage roots after the associated relationships are proved. Existing CFG,
region, loan, move, drop, break/continue and return processing remain responsible
for execution and cleanup.

Source-derived Clone declarations retain their ordinary argument conditions.
Only the validated canonical Iter declaration uses the explicit FieldsOnly
argument policy; its actual shared-reference field still has to satisfy Clone.
Imported/source lookalikes cannot obtain that policy from names or computed
property bits.

## Demand and immutable snapshots

Custom-only `for` loops and source array-trait `.iter` winners reserve identities
without constructing Iter fields, derives or the four collection contracts.
Typed shared array/slice/Iter demand enters the existing ImplHeader dependency
and body retry. The iterator expression is evaluated once; retry performs no CFG
or call-plan publication. Unknown and projected heads remain pending. Shape
filtering cannot change source-header applicability or turn deferred absence
into negative evidence.

Constant-header readiness and selection readiness are distinct. Exact existing
pending-candidate classification governs synchronous selection, method
conditions and completed dispatch caches. Unrelated closed goals retain cache
hits while latent collection headers exist. The source-free activation facade
completes ordinary associated/method conformance before a Validated consumer
can observe the canonical header.

Late Iter formation uses the existing outlives, variance and sizedness solvers.
The independent sized leaf rejects incomplete/dependent or foreign schemas.
A unique Rules Arc appends once; a shared Arc preflights charged work and full
capacity before a one-time copy. Earlier snapshots retain their rules and cannot
intern/use the new nominal through stale sizedness information. Old entries
remain unchanged; failed activation cannot publish complete factory evidence.
