# Original conditional components

The constant provider now proves a deferred anonymous original together with its
actual original parent and sibling output dependencies. This is original-body
preparation, not permission to execute a selected anonymous instance. The unchanged
Rust-positive `inline-query-context/{closure,paid-lifetime}.rs` sources complete
`pipeline::analyze_source`; their remaining checked execution boundary is
`anonymous specialized output interface is not implemented` at bytes309/333.
Removing the outer `'a:'b` relation rejects at the ordinary lifetime proof.

One lazy typed index records real function, initializer, closure and inline body
owners and their exact output links. It expands a connected original component
once, only when the child's region proof actually requires its parent. The
region query returns either an independent solved body or a needs-parent outcome;
it cannot hand an unresolved conditional body to ordinary loan checking.
Independent children keep the prior single-body proof and demand order.
Successful full promotion, region, ownership, storage and cleanup/loan
verification precedes publication of any member. Cached sibling ports reuse the
completed originals. Missing, foreign, cyclic or stale owners reject; the index
and failed work remain accounted, but failed components publish no parent/child
template, Code or execution root. No source is reparsed to construct this index.

The ordinary template partition is unchanged. A separate lazy sidecar retains
parents which belong to original proof context but are not executable template
candidates. Exact candidate originals enter the existing template collection;
ordinary context parents do not enter `Checked::get`, closure or anonymous runtime
lookup. The normal lowerer reproves the combined originals before demand.
Contracts are joined only by exact BodyKey/source/header/link identity. Current
source contracts displaced by provider contracts are moved into the sidecar and
also rechecked, scoped to those components. Thus later source debts and retained
provider dispatch debts both remain mandatory, without proving unrelated
executable bodies twice. Publication and override application are transactional.
Associated-initializer and component consumers reuse the same completed original
and its paired contract in either demand order. They do not drain the semantic
fact cursor a second time or silently rebuild a contract without its debts.

No OutputLink is cleared, no conditional conclusion is made an assumption, and no
new execution Permit or shared request/owner variant exists in this change.
Actual anonymous specialization still rejects the conditional interface. Its next
required step is to retain exact checked child-to-parent requirements as ordinary
parent goals, transport them into the actual selected parent, and prove that
parent before a child can consume its payment. A bare InlineInstance or a proved
context-only source parent cannot establish that payment.
