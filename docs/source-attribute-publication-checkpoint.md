# Source attribute publication boundary

The closed Source2024Functions producer checks selected source function and
trait headers before creating a payload or descriptor. Retained `must_use`
contracts and inline hints are explicit unsupported transport errors at their
actual configured owner and attribute span. The walk uses the existing staged
DefId mapping, authenticates row kind/name and source declarations, and consumes
the semantic queries. It does not scan source text or add a header table.

The publishing `Source::complete_payload` owns this check. Its single library
caller retains typed query errors and the existing warning carrier. Internal
collection failures retain their previous diagnostic adapter. The production
flow owns one Report and its prepared facts throughout staging and publication;
the guard adds existing provider/header checks, not a new general arena token.

`Stage::begin`, complete source inspection and numbered inspection remain unpaid
development views. They still accept the complete qualified provider family.
Inspection does not establish that omitted attribute contracts were absent.

A bodyless required method currently emits an `unused_attributes` warning for
inline and retains its advisory hint. Closed publication rejects that retained
hint conservatively. A wider transport must represent actual applicability as
well as Hint/Always/Never. Named struct, enum and union declarations remain an
earlier explicit source-profile boundary; their marked and unmarked controls do
not claim an attribute-specific rejection.

No codec, schema, profile, node, declaration or body fields change. Old Functions
metadata remains Unknown for imported attribute queries, including metadata
produced after this guard. Local map misses do not mint serialized KnownAbsent.
Future wider transport must carry complete checked Absent/Present states,
canonical declaration/owner-site identities, optional must-use reasons and
inline applicability. Other semantic attribute families remain separate work.

The focused plan contains four new private groups plus the existing public
Functions/fresh-client proof and unchanged full-provider inspection control.
The source variants and publication predictions are frozen in
`pa31/tests/spec/source-publication-attributes/contract.json`. Compiler
qualification is pending; no broader suite or native result is claimed here.
