# Selected cleanup value history (proposal, not a qualified implementation)

The connected consumer has a real source-definition positive for `prknow`,
`prmove`, `tagmv`, `taglif`, `taggen`, `tagshr`, `aryone`, `arybig`, and `arysm`.
`leaves-consumer6/receipt.json` binds the strict/public attempt. All nineteen
frozen cleanup negatives pass, including unchanged default-policy `tagpar` and
array opponents. Seven independently Rust-positive default-policy cases remain
required: epart, epart2, snest, dwrap, dpass, dstrct, dowmv. The dborrow invalid
body is still masked by their same over-strong static history request. The other
five ordinary-body opponents have not run past that first group failure.

The exact current defect is a whole-type partial-history request. Rust retains
VALUE qualification: known Good(C,C) has only C history after moves, and
S{E::Good(C)} has only C history. Whole Destruct(E/S) invents obligations for
never-possible Bad(N). Unknown Pair(N,C) must retain actual N history and remain
a default-policy E0493 rejection. An actual precise request can omit only that
historical non-access demand, preserving all real current accesses.

Superseded first sketch (not implemented; the compiler-law table below corrects its move and replacement assumptions):

* Keep the current qualifier plane and add one parallel historical plane at a
  checked offset in paid Tags. Drop the inadequate per-coordinate partial flag.
  No Body, Plan, Proved, Code, Store or persistent authority table grows.
* Index each transfer once. Constructors, copies and new values write both
  planes from incoming CURRENT qualification. Replacement writes only its real
  destination after the existing old-value cleanup snapshot. Capture source
  scratch once, then write both mapped destinations.
* A real owned field move clears current qualification while preserving its
  parent-owned history. A whole root move clears both source planes. Copy reads
  do not clear. Merged array coordinates remain conservative.
* Existing actual tag refinement masks both planes only for that source payload.
  Fresh/sibling values, own Drop and unknown/alias writes remain independently
  conservative. No CFG, physical initialization, read, move or loan fact changes.
* Snapshot visits each coordinate once. A current need emits its actual
  OwnDrop/Whole request with access=true; historical-only need emits the same
  request with access=false. Traverse the union of actual current/historical
  variant possibilities. Full semantic type/purpose reauthentication still uses
  the existing shared declaration field fold.
* Default policy proves history. Only the authenticated source precise request
  may omit non-access history. OwnDrop never satisfies Whole. Explicit whole
  Destruct bounds continue through the ordinary full-type proof kernel.

Expected record deltas must be measured, not assumed: Tags gains one checked
mapping offset; Node can lose its partial Range; Release can lose ancestor
history-walk identity. Existing Copy scratch need not double. All additional
block-table words, writes, ranges and arithmetic must be prepaid and bounded
before publication. No enum means no partition/allocation. Large arrays retain
one sparse element coordinate, independent of length.

Required before promotion: remaining original positives and actual body causes;
current/default/precise/move/Copy/alias/OwnDrop/history opponents; exact full
argument and purpose controls; a genuine replay-owned foreign Selected swap;
source-only/ordinary noise and shared-declaration scaling; actual native
cleanup behavior. The foreign swap is private-only and has no executed local
receipt yet. No ownership state has been added merely from inspection.

CTFE cleanup scheduling/execution remains required. Physical Code activity and
the interpreter fence remain unchanged. Zero-goal const-definition retention
uses only the actual authenticated source owner and does not authorize execution.

## Pinned compiler law and independent pending transfer table

Primary local sources are the pinned compiler's
`compiler/rustc_const_eval/src/check_consts/{resolver,qualifs}.rs`; their exact
SHA256 bindings are in `pa31/tests/spec/source-const-cleanup/histo.json`.
This table is source analysis, not a claimed reference observation. The eighteen
frozen raw controls must execute independently before changing the producer.

| Event | Qualification law | Authority/limit |
| --- | --- | --- |
| Function parameter / ordinary call result | Use the actual complete type's possibly-qualified property. | NeedsNonConstDrop first checks real needs_drop, then genuine scoped const Destruct; a raw OwnDrop-presence bit is insufficient. |
| Structural aggregate | Propagate operand value qualification. | Union and an ADT with its own destructor use the full type property; actual own Drop debts remain independently required. |
| Copy or move operand | Compute the same incoming qualification before operand consumption. | Projection walks filter by each projected type's possible qualification, then consult root-local qualification. |
| Whole local move | Clear source qualification only when no sticky mutable/raw exposure exists. | Destination inherits the incoming qualification first. No physical initialization permission follows. |
| Projected field move | Retain parent-local qualification. | Physical moved-field access still rejects normally; static eligibility history is independent. |
| Assignment / replacement | A qualified incoming value sets local qualification; an unqualified value does not clear existing qualification, including a full overwrite. | Old-value cleanup order and actual replacement field/root identity stay authenticated. |
| Mutation-capable borrow/address | Add conservative qualification when the borrowed type can qualify, and set sticky borrow state. | Shared Freeze borrows do not add it; raw pointers conservatively may mutate. |
| StorageDead | Clear local qualification and sticky exposure. | Storage schedule remains the real source schedule. |
| Join | Union possible qualification and sticky exposure across incoming branches. | A later sibling/fresh tag test cannot erase another local's qualification. |

The proposed per-coordinate plane must obey this local/projection law rather
than silently implement a more permissive analysis. In particular, a sibling
whose actual value can qualify may contaminate another projection whose TYPE
could qualify. Likewise, constructed `W<T:Copy>` and an unknown parameter
`W<T:Copy>` need separate controls: real projected-type no-drop filtering is not
an explicit const Destruct proof for T.
