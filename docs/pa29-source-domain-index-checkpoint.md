## Interface and authority boundary

`source::HeaderIndex::new(&SourceRows, base_bytes, &mut Work)` preflights combined
row capacities and builds a declaration/header ledger plus the existing shared
ScopeIndex. It verifies real lexical declaration ownership, clause ranges and
canonical membership, associated conformance, required versus provided body
coverage, complete formal identity and supplied local bindings. Required methods
retain genuine formals without fabricated body-local declarations.

`HeaderIndex::domains(&mut Work)` constructs a borrowed `DomainIndex` after binder,
type/application and operation/input coordinate checks. `DomainIndex` exposes
only counted `work`, `retained_bytes`, `peak_bytes` and `binder_contains` queries.
ScopeIndex adds `parent` and `type_argument_position` queries without fields.
Every query charges success and rejection. Private construction stages drop on
error; no partially built index is returned or published.

One binder forest traversal uses CSR child/query buckets and an active path to
resolve labelled bound-region depth. Shared preorder intervals answer ancestry
queries without chain walks. Public late binders check retained slot-reference
coverage, owner, kind and counts; canonical index uniqueness needs the narrow
follow-up described below. Type/application recipe DAGs are summarized once for
parameter scope, original free allocation and current binder dependence; each
caller root checks that summary. Recursive callable edges are distinct from
cyclic recipes. Explicit application ownership and all unused type-formal arity
remain checked; larger unsupported forms reject.

Each Call must retain its exact value, evaluation site, request, target,
application, semantic owner-context effect, actual late opening and method Self
mapping. CFG/local/projection/value/scope/storage/owned-rvalue/normalization and
raw obligation coordinates are checked independently. Copy inputs stay queries;
regional assumptions cannot carry trait permission. No source identity is
fabricated and no Environment/Contract success becomes wire authority.

This is data/index completion. Full substituted signature equality, operation
typing and complete operation-derived obligations remain mandatory before
acceptance. Unsafe Calls, early/captured regional forms, wider artifact remaps
and application-signature recipes remain unsupported here. Authenticated neutral
role/header installation, B46 Required reconstruction with the exact defining
Environment Arc, fresh promotion, original/instance/loan/active-cleanup proof,
complete contextual-name provenance rejection and stability import/use semantics
remain required before the source-client transaction can publish anything.

No Body/Owner/Contract/Value/Package fields, codec bytes or profile tags change.
The new allocations occur only when the source-data index is requested; ordinary
and no-import compilation do not construct it. ScopeIndex's storage is reused;
there is no second body catalog, duplicated original body or flattened ancestry
