# Callable result inference before structural consumers

Every source is manifest-listed with a predicted object/status and native outcome
before implementation. Generic FnOnce/FnMut/Fn output is reused through ordinary
proof before tuple/nominal fields, array indexing or calls; no result shape is
invented from a consumer. Positive mains exercise real returned values, mutation,
movement and borrowed data. Explicit result/function pointer/custom trait controls
separate this from general associated-result inference. Negative controls retain
field/input/result/kind, move, borrow, lifetime and quantifier requirements.

The owning packet plan and original failing versions are retained under
obj/parallel/callable-results/. References may be generated only after independent
review and complete candidate/native qualification.
