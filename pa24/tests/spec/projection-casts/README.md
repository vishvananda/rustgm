# Casts wait for a closure's actual inputs

PA24 is the earliest owner: closures use PA20 associated types and earlier scalar
casts. The minimized generic Read call reproduces the core indexing failure
without an Index role. All inputs and outcomes are declared in contract.json and
the assignment manifest before independent checking or text generation.
Explicit argument types remain a control. Later callers, generic parents, nested
closures, tuple inputs and early returns must infer normally. A function-item
result checks real pointer decay when the late type is not an integer; record,
unpaid-trait and ambiguous uncalled closures reject normally. Width/noise inputs
freeze bounded work and ordinary native equality. Source-role companions remain
in PA31; these declarations supply no source-role or metadata authority.
