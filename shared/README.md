# Shared contracts

[LowIR](lowir.md) is copied unchanged from the original CPPGM baseline
`905bd7e4412a2d77d88694fe6abc7f3e1c27bce1`. It describes the text format.
RustGM assignment handouts specify the Rust lowering conventions.
`CPPGM-NOTICE` retains inherited attribution. The pinned release documents
the [LowIR library API](https://github.com/vishvananda/cppgm/blob/v0.12.0/docs/lowir-library.md).

The [pinned Rust Reference](../doc/README.md) describes source syntax.
Each RustGM handout states its subset. References to numbered assignments
in the LowIR baseline use CPPGM's course numbering.
