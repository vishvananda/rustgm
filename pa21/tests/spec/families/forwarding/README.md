# Generic associated family forwarding

These nineteen ordinary-source cases exercise shared, inherited and mutable
reference forwarding through genuine generic associated declarations. Each
source is registered in the PA21 manifest. `predictions.json` binds source bytes,
the independent Rust1.98 metadata packets and expected outcomes before
candidate observation. Six type-definition controls, six method controls and four scope controls
include missing parent/outlives bounds, a wrong receiver/result, invalid static
lifetime widening and a valid noninjective family whose applications both
normalize to u32.

An associated declaration's captured binder needs its actual immutable caller
environment, including implementation and own member inputs. A parameter-only
fallback loses those requirements. Method conformance must normalize both real
signatures, compare complete rigid type/const structure without inferring opaque
projection inputs, and retain the original directed lifetime proof. A structural
match grants no trait, lifetime, body or executable permission. Fresh mapped
family applications need their real input conditions prepared through the
existing memoized outlives cache before the immutable lifetime solver reads them.

These ordinary prerequisites also occur in the unchanged AsyncFn reference
implementations. Their source roles and protocol consumers are owned by PA31;
future execution, cancellation and associated/body metadata remain separate
requirements. This packet neither releases PA21 nor establishes a library build.

Three additional executable consumers observe shared/inherited reads17 and a
mutable forwarded write29. They retain actual source methods, caller borrows,
specialized bodies and independent Rust/CPPGM execution.
