# Callable family input formation

Eighteen declared outcomes separate an unused callable signature from an actual
call. Complete family conditions containing a callable local defer under
RFC1214; they grant no body premise. Outer lifetime/static conditions remain
required. Captured and nested binders, invalid static returns and an output
lifetime unconstrained by inputs retain their own checks. The independent Rust
checker runs every complete source before the ordinary full RustGM lowering.
An implementation-selection condition is not a family formation condition.
No implicit AsyncFn implementation or generated polling body is supplied here.

Fresh call lifetime arguments may use a complete expected result application as
a candidate before opening the callee signature. Rigid Self/type/const identity,
repeated-slot consistency and nested-local escape checks remain. These choices
supply no caller premise: all actual argument, formation, result and loan proofs
still run. Wrong subject/const, incompatible universal slots, nested captures,
local/static escapes and independent calls are explicit opponents.
