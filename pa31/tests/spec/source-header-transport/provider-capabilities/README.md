# Provider capability opponents

These declared custom header cases distinguish invalid Rust from valid but
unsupported arbitrary semantic attributes. They do not replace either unchanged
full provider above this directory. Expected Rust/candidate outcomes are frozen
in contract.json before oracle execution. A requested feature or diagnostic
marker supplies no trait, Copy, const-destruction or execution proof. Preserve
all hypothesis mismatches independently of later corrections.

The historical candidate column remains frozen. The current fundamental-policy
and applicable-trait producers now accept user-fundamental, lookalike-fundamental
and user-specialization declarations, matching their existing Rust0 outcomes.
The maintainer matrix uses those current expectations; general coinductive
semantics and unsupported transport still require implementation. See the
[fundamental checkpoint](../../../../../docs/pa31-fundamental-policy-checkpoint.md).
