This profile transports the real regular stable compatibility message, separately
from deprecated declaration metadata. The message is opaque guidance. Actual leaf
availability is checked before prefixes; only otherwise-denied module prefixes
produce `deprecated` events. Feature, const, unsafe, privacy and body permission
remain independent. Local/stable/enabled paths stay silent. Distinct denied
prefixes produce distinct warnings; neighboring grouped imports cannot share a
leaf's note. Source expectations fulfill only at actual checked uses.

The NoCore foundation is unchanged from the existing source availability fixture;
its source roles are genuine declarations. Provider functions are authored ordinary
source bodies, not replacements for original transmute or core intrinsics. The
independent standard-library reference matrix and primary compiler revision are
retained in the contract. Fresh RustGM consumers must decode the v6 artifact into a
fresh Store and preserve policy and actual body proof. Profiles 0–5 retain their
bytes and reject compatibility rows. V6 source producers reject every active
`deprecated` declaration; this explicit guarantee applies only to a leaf whose
actual canonical artifact is v6. Aliases/reexports of older artifacts remain unknown.

Full core metadata/artifacts and unrelated promotion/SIMD/nominal contracts remain
required. This checkpoint does not enable a module or invent a deprecated function.

by all four active pinned uses. Associated paths whose module decision needs an

stand in for its actual member. Completing that selected-leaf continuation remains
