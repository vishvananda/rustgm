# Aggregate field availability contract

PA31 owns direct/inherited field API policy; PA12 owns actual field identity,
constructors, patterns and storage. PA29 must transport authenticated field
policy before admitting external consumers. These required outcomes are declared
before observation; this packet is not an implemented component or passing
assignment. Const annotations cannot manufacture const-call permission, and
same-crate field access remains separate from external unstable API admission.
The corpus includes tuple/named/union/variant fields, stable and unstable
inheritance, real construction/access/pattern/const consumers, generic and
macro/cfg contexts, private owners, duplicates and wrong annotation targets.
Original core's LIB-143 reduction and remaining transport duties are tracked in
[the blocker queue](../../../../docs/library-build-blockers.md).

The [qualified local checkpoint](../../../../docs/pa31-field-policy-checkpoint.md)
now matches every declared outcome through real typed and native consumers. The
v1 manifest retains its original pre-observation pending declaration; whole-PA
release and authenticated imported policy remain required.
