`num/shells/legacy_int_modules.rs`, whose `legacy_int_module!` definition computes its
diagnostic identity with `concat!(stringify!($T), "_legacy_mod")`. The contract
binds that original file's hash. Sources retain real source-declared builtin
macros and ordinary declarative definitions; kernel selection must authenticate
the actual declaration rather than a call's spelling.

The22 declared metadata outcomes cover direct/nested values, raw strings,
opaque expression forwarding, genuine aliases, shadowing, cfg removal, signed
concat operands and rejecting nonliteral/byte/block/multiple/duplicate values,
missing macros and missing feature authority. Module attributes resolve macro
imports in that module. The external-module pair additionally preserves its
declaration file. One ordinary exported function must execute and print7 through
an independent C observer, matching pinned Rust.

while a module-local import and a function attribute accept. The isolated
no_core function needed its genuine Sized family; an unrelated external child
unit constructor needed Copy and was removed to isolate lookup. Original failed
inputs and observations remain in the local evidence packet. The final
reference-v8 receipt accepts all declared outcomes; qualification records the
candidate checks separately. No diagnostic name grants a body or trait proof.
