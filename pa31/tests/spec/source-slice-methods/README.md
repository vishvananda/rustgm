# Source slice-method consumer

These planned PA31 inputs retain the exact pinned `str::len`, `str::as_bytes`
and `slice::len` methods and attributes. Their supporting no-core Pointee
protocol is an authored reduction: complete upstream Metadata bounds and
DynMetadata remain required. No ordinary library method is a compiler factory.

The independent packet observed metadata acceptance and native `6 3 4\n` for
the actual method chain. Seven marker cases cover target, gate, arguments,
duplication, foreign ownership and unsafe wrappers; three tag cases cover
inherent versus free/trait methods. The initial generic tag input failed on a
missing Copy prerequisite. Its separately frozen complete companion accepts
both implementation and method generics. GenericRequirement::None imposes no
count or receiver/name rule. The earlier incomplete native setup triggered a
rustc delayed ICE and is preserved as infrastructure failure in raw evidence.

Candidate source/const/native proof is pending. The role alone grants no

full dangerous_implicit_autorefs lint remain required; the first consumer uses
