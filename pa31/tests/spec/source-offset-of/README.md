# Source offset_of contracts

These 57 independently frozen fixtures retain the complete offset_of requirement.
PA31 owns source feature and declaration authority; PA4 supplies grammar and
PA12/18/25/28 supply field layout, generic substitution, inline constants and the
actual intrinsic. PA31 remains planned. No generated course references exist.

`contract.json` discovers every primary source and the auxiliary exact macro.
`original-macro.rs` is byte-exact Rust 1.98.0 core/mem/mod.rs, UTF-8 bytes
[58317,58764), revision 88d9e12ae178fab0fb5cc050a94da85685d449ea. Its original
MIT/Apache-2.0 attribution is retained through third_party/sources.json and the
repository notices. Native original cases include this macro unchanged.

The immutable independent packet contains 114 metadata observations in editions
2021/2024, eight native builds/executions and two explicit upstream object
compiler failures. Its index SHA-256 is
1db700eebb66bd54986a86d599f00ad968c39253252648c1f103f5c765ff5a02.
Original predictions and all 18 disagreements remain recorded. Fourteen initial
positive hypotheses lacked the distinct core_intrinsics const-API request;
const-api-followup adds only that request. Two disabled-syntax hypotheses were
wrong: builtin_syntax remains a hard parser gate under cfg removal. The final
30 followup metadata observations match their separately frozen predictions.

Expression and literal captures of decimal tuple members are valid, including
1.2 and 0. Grouped paths and hexadecimal/suffixed indices reject. The actual
emitted builtin name can consume its genuine macro allowance; an opaque caller
expression cannot acquire it from an allowing wrapper. Enum offset permission
requires the actual crate request, including when the macro allows that feature.

The four native Rust programs print, in both editions:

- original generic Option<B>: `1 4 8 0`;
- distinct fields of one callable instance: `0 8 16`;
- tagged variants and niche layout: `1 2 2 0`;
- nested, packed and union offsets: `8 1 0`.

These establish independent Rust behavior. They do not establish RustGM layout
or execution. A source parser checkpoint must preserve every such positive as
required pending until genuine field selection and reached constant calls work.
Sized fields of DST prefixes and feature-enabled statically aligned slice tails
are also accepted Rust and remain required. Runtime intrinsic metadata succeeds,
but object generation hits pinned rustc ICE101; retain that failure without
calling it a language rejection or using it to justify a fabricated answer.

The parser keeps the container and original field-expression roots. Decimal
literal-shaped captures produce typed projection nodes with original spans;
no rendered-text parsing or alternate source macro is allowed. Layout execution
must authenticate each actual variant/field call and defer generic containers.
The size/alignment cache keyed only by callable Instance cannot store offsets of
different fields. See docs/pa31-offset-of-plan.md for the remaining full exit.
