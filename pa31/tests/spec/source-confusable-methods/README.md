# Confusable method-name source contract plan

This packet preserves source hashes and predictions frozen before execution.
The independent pinned Rust batch matched all160 outcomes across both80source
clusters. Source validation is drafted; candidate compiler/runtime qualification
remains pending. Only Confusables is an observed core blocker (cell.rs508).

The pinned ConfusablesParser accepts a nonempty list of string literals on an
actual inherent method, including associated static functions. It requires
rustc_attrs or the real macro attribute-envelope allowance. Repeated attributes
combine names; duplicate names, empty string values and arbitrary string contents
are not silently turned into identifier validation or hard duplicate errors.
Trait declarations/defaults/implementations and non-method owners reject.

The actual consumer uses these names during failed method-lookup suggestions.
Neither method-call nor qualified paths acquire a successful alias. The packet
retains genuine unknown-name, const, unsafe and shared-mutation opponents and
actual mutation/const positives. Macro-generated meta and passthrough item cases
retain the attribute-envelope distinction established by the LIB109 reference.

A future source producer should reuse the existing configured-owner pass and
actual impl/member identities, with paid bounded parsing and current source/
effect/owner replays. Do not reuse word-only or hard-duplicate rules. Broad
suggestion production and imported suggestion metadata remain explicit required
work; source recognition cannot grant method lookup, mutation or call permission.
Original Cell::replace/RefCell::replace intervals and full source hashes are bound
in contract.json. The fixtures do not replace those algorithms or whole artifacts.

`qualification.json` binds the independent receipt and unexecuted candidate
requirements. The transient draft performs one declaration lookup, keeps its
first annotation inline, and visits only actual present kinds. Repeated
Confusables lists are all validated, without allocating a successful-name table.
No future imported diagnostic consumer may treat absent wire intent as permission.
