# Source Debug array observer

This explicitly authored NoCore protocol observes seven-field record, tuple and
both enum helper calls. It uses genuine source language roles, dynamic Debug
calls, shared references and array-to-slice coercions. A checked generic accessor
reads the known seven positions; its C guard aborts before any out-of-range
pointer access. The formatter trace preserves all names and field values.

The observer Formatter, unit Result and tracing helper bodies are test code.
They do not replace original core Formatter, Result, builders, iterator or Index
bodies. The adjacent debug-field-arrays cluster retains exact original helper
and compiler recipe intervals. Whole original core/alloc/std artifacts and full
formatter execution remain required.

The contract is frozen before each observation. V1–V5 failed predictions remain
in maintainer obj evidence: invalid feature requests/missing Index protocol,
missing const stability, then actual DynMetadata/Unpin/UnsafeUnpin object-code
requirements. V6 keeps the generated dyn/slice array recipe and expected trace,
uses the ordinary checked accessor for its authored observer, and supplies the
actual source roles. Independent Rust metadata/object/link/native all pass.
