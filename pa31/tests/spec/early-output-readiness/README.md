# Early associated-output conformance

These authored PA20/PA25/PA31 protocols force a named constant UFCS call while an
array annotation is being completed. `Produced` has a genuine associated type,
its ordinary declared bound, an associated constant and a real source method.
The qualified source Div/Location foundation is unchanged. The expected bound
is7; all six inputs have independently frozen Rust metadata outcomes.

The early producer accepts the existing closed primitive owner profile and
uses the normal associated-type, method and constant conformance kernels. It
indexes only the requested actual impl and trait member buckets. Existing
functions-only and methods-plus-constants seals retain their exclusions.
Missing/extra types, failed bounds, wrong method types and ordinary impls cannot
authorize const execution. Source/arena identity, cached rows and failed work
remain separate tests. No compiler body or metadata permission is introduced.

This is a finite source consumer. Broader early owner profiles and original
library artifacts remain requirements of their owning assignments.
