The pinned `FromCoroutine<G>` Clone declaration is the actual original-core
LIB079 storage boundary. Its exact source interval and unchanged work/storage
limits are frozen in `contract.json`. The compiler must preserve ordinary derive
output and permissions while paying actual image, origin, token and field
capacity growth before allocation. Spare capacity is reusable. Parser scratch,
owned syntax and installation remain separately charged; failed attempts count.

Private controls separate fixed provider setup from repeated tiny derives and
long identifiers, inspect warm receipt work/bytes and oppose rejected payment.
