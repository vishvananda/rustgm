# Actual source variadic runtime packet

This is an attributed active source consumer, with independent predictions frozen
before candidate runs. It retains actual standard nominal/representation/lang/
variance types and reached Clone/Copy/Drop/next_arg/va_arg/va_copy/va_end bodies.
The private ffi::va_list implementation domain is preserved. Unneeded formatting,
comparison, hash and default generation is omitted from this separate cutout;
full original modules and macros remain in original/ with their hashes.

stdpred.json preserves seventeen initial std-backed controls; cvpred.json
retains ten c_void declaration/ownership outcomes and its original by-value C
observer. cutpred.json, rtpred.json, dcpred.json, dcfix.json, workpred.json,
fixpred.json, runpred.json, rdpred.json, cvloc.json and cvloc2.json bind successive
independently frozen inputs, corrections and exact native expectations.
initial2/ through initial5/ preserve earlier setup bytes. feature.tsv selects
sixteen unchanged positive requests from the stage-1 initial/ packet.

The native run/rzro/rorder/rfixed/rfrom successors append a real application
panic_handler → abort body; original sources and missing-handler link failure
remain. Reference objects explicitly disable overflow checks; rorder's separate
qualified run also disables debug assertions. These valid-input cursor observers
do not qualify checked arithmetic/alignment/null/panic behavior.

The grouped vactx integration tests run these files in suite_traits. Three
Rust-positive requirements remain explicitly named: const cursor definition,
executed constant cursor call, and original c_void by-value C echo. They are
not parity negatives. cvloc2 is a distinct ordinary constructor/move/cast observer
and does not replace the original ABI input. PA31 remains planned without a
grading manifest; these are maintainer contracts.
