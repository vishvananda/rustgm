# Closed source FnOnce invocation continuation

These are declared development controls, not a released assignment or a claim
that the pinned core crate compiles. `contract.json` freezes source hashes and
independent Rust outcomes before this successor is executed.

`original-native29.rs` and `original-nonconst-reject.rs` retain the exact bytes
of the earlier source-trait hypotheses. Their role declarations exercise actual
source identities. The positive calls a const helper through its declared
`F: [const] FnOnce(u8) -> u8` requirement and must produce 29. Acceptance of a
bound without executing the callback does not satisfy this control.

The bounded executable profile is an owned, complete function item with a safe
Rust `fn(u8) -> u8` signature. Its defining Conditional clause remains intact;
each reached constant call must pay the copied Const obligation using its own
checked caller. Cached code and retained clauses supply structure only.

The same helper is valid at runtime with a function pointer. That defining-body
case must not accidentally authorize a constant function-pointer invocation.
Unused ordinary bounds, a non-const function item, missing call facts, mismatched
body owners and unpaid direct interpreter roots supply the opposing controls.
`ordinary-function-root7.rs` is a genuine const-source positive, distinct from
tests that forge a runtime body's constant-context bit.

`conditional-target-required.rs` is Rust-positive and remains required. The
first profile explicitly diagnoses its callback's own Conditional debt until
an Invoke-bound reached payment witness is implemented. Its expected rejection
in this checkpoint is an implementation boundary, not a Rust-invalid program.

The `work/repeated-{8,32,128}.rs` axis counts repeated reached calls to the same
full helper instance. Private cold/warm replays must count one fresh outer
payment per reached use and keep retained requirements unchanged. This axis
does not stand in for distinct callers or distinct complete instances.

Evidence is retained under
`obj/parallel/pa31/const-callable-execution-v1`. The independent runner is
prepared there but must execute through the normal resource/storage guard.
No source, native or after-layout success is claimed before its receipts exist.
