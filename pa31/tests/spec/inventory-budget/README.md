# Inventory budget ownership

The source-provider and local macro fixtures must complete real library policy
inventories using their existing authenticated source cost owner. Standalone
staged libraries retain their existing finite fallback. A cost payer grants no
API feature, language item, macro allowance or const permission.

The private boundary tests predeclare these requirements: inventory and earlier
source work accumulate under one configured work/attempted-storage limit;
retained library storage survives later macro memo checks; all three first
failures remain sticky, including failed attempts. Completion releases only
capture tables and retains the finished policy/declaration/import storage.
Owner tables reserve on their actual scope/declaration/import axes. Policy
inheritance, const/default distinctions and source identity controls remain
required. No successful core/alloc/std artifact is inferred from these fixtures.
